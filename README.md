> 💡 **Почему IP-список надёжнее доменного:** по [документации Amnezia](https://docs.amnezia.org/documentation/instructions/vpn-split-tunneling/), домен из списка резолвится в IP один раз при добавлении и дальше автоматически не обновляется. CIDR-подсети работают всегда. Доменный список удобен для точечной настройки, IP-список — для режима «всё российское напрямую». На слабых устройствах большой IP-список может импортироваться заметно дольше — это нормально.

> ⚠️ **На Android и iOS берите `amnezia-ip-lite.json`, а не `amnezia-ip.json`.** 12 800 подсетей — это столько же маршрутов в таблице VPN-интерфейса, и мобильные клиенты на таком объёме не поднимают туннель вообще: подключение просто не устанавливается. Lite-версия содержит ~650 подсетей и лишена этой проблемы.

## 🚀 Зачем это нужно?

Раздельное туннелирование делит трафик на два потока:

- **Зарубежный и заблокированный трафик** (YouTube, Instagram, Twitter, независимые СМИ) идёт через зашифрованный туннель вашего VPN-сервера.
- **Российские сервисы** (банки, Госуслуги, маркетплейсы, Яндекс) идут напрямую через провайдера, минуя VPN.

Что это даёт:

- 🏦 **Банки не блокируют вход и переводы** — никаких «подозрительных входов из Нидерландов», капч и звонков из службы безопасности.
- 🏛️ **Госуслуги, налоговая и Мос.ру просто работают** — госсайты, параноидально режущие иностранные IP, видят ваш обычный адрес.
- ⚡ **Максимальная скорость на локальных сайтах** — без лишнего крюка через другую страну.
- 💾 **Экономия трафика VPS** — тяжёлое видео с Кинопоиска, VK Видео и RuTube не съедает лимит вашего сервера.
- 🔕 **Включил и забыл** — Amnezia работает постоянно, а интернет ведёт себя так, как должен.
- 🛡️ **Меньше шансов на блокировку вашего сервера** — вы не гоните через VPS трафик к российским ресурсам, которые логируют и жалуются в РКН.

## 🛠️ Как подключить в Amnezia VPN (1 минута)

1. Скачайте файл 👉 [**amnezia.json**](https://github.com/lib4u/amnezia-tunneling-ru/releases/download/latest/amnezia.json)
2. Откройте **Amnezia VPN** (Windows, macOS, Linux, Android, iOS).
3. Перейдите в **Настройки** (⚙️) → **Подключение**.
4. Откройте **Раздельное туннелирование сайтов** (Site-based split tunneling).
5. Выберите режим: **«Адреса из списка НЕ должны использовать VPN»** (Addresses from the list should not be accessed via VPN).
6. Нажмите **⋮** (три точки) в правом верхнем углу → **Импорт** → укажите скачанный `amnezia.json`.

Готово. Российские сайты пойдут напрямую, всё остальное — через туннель.

### 👨‍👩‍👧 Для администраторов: раздать настройки семье и друзьям

Не нужно настраивать каждое устройство вручную:

1. Настройте раздельное туннелирование у себя, как описано выше.
2. В настройках сервера выберите **Поделиться подключением** (Share connection).
3. Сгенерируйте `.vpn`-файл или QR-код — **настройки туннелирования сохранятся внутри профиля**.
4. Отправьте файл/QR пользователям: после импорта у них всё работает из коробки.

## 📡 Как подключить на роутере GL.iNet

Роутеры GL.iNet с прошивкой 4.7+ умеют брать правила VPN-политики из онлайн-файла ([документация](https://docs.gl-inet.com/router/en/4/tutorials/how_to_configure_domain_and_ip_filtering_rules_for_glinet_routers_via_an_online_text_file/)). Для них есть `glinet-ip.txt` — те же 12 800+ подсетей, что в `amnezia-ip.json`, по одной на строку (одиночные адреса — без `/32`):

```
https://raw.githubusercontent.com/zz52gw8/amnezia-tunneling-ru33/main/glinet-ip.txt
```

1. В веб-интерфейсе роутера откройте **VPN** → **VPN Dashboard** и переключитесь в **Policy Mode**.
2. В правиле туннеля в поле **To** выберите **Exclude Specified Domain / IP List** (при **Via** = **Use VPN**) — в туннель пойдёт всё, кроме российских подсетей.
3. Переключите **Input Mode** с **Manual** на **Subscription URL**, вставьте ссылку выше и примените.

Подписку роутер перекачивает сам раз в сутки, а сам файл меняется только вместе с источником: v2fly/geoip публикует новые данные примерно раз в месяц. Названия пунктов приведены по [документации прошивки 4.8](https://docs.gl-inet.com/router/en/4/interface_guide/vpn_dashboard_v4.8/), в других версиях они могут отличаться.

## ⚙️ Как устроено обновление

Никакой ручной работы — всё делает GitHub Actions:

1. **Каждый день в 00:00 UTC** workflow клонирует свежую базу [v2fly/domain-list-community](https://github.com/v2fly/domain-list-community).
2. Скрипт [`scripts/extract_amnezia.py`](scripts/extract_amnezia.py) берёт 28 корневых российских категорий (`category-ru`, `category-bank-ru`, `category-gov-ru`, `yandex`, `vk`, `sber` и др.) и **рекурсивно разворачивает все `include:`** — получается 80 категорий.
3. Результат конвертируется в формат Amnezia (`{"hostname": "...", "ip": ""}`), дедуплицируется и сортируется.
4. Параллельно скрипт [`scripts/extract_ip.py`](scripts/extract_ip.py) скачивает полный список российских подсетей из [v2fly/geoip](https://github.com/v2fly/geoip) (`ru.txt`), отбрасывает IPv6 (Amnezia поддерживает только IPv4) и собирает `amnezia-ip.json`. Приватные диапазоны (`private.txt`) сюда намеренно **не** включаются: в split tunneling список означает «гнать напрямую», и `127.0.0.0/8`, `10.0.0.0/8`, `192.168.0.0/16`, `100.64.0.0/10` увели бы в туннель loopback, шлюз локальной сети и CGNAT-адрес клиента, полностью сломав подключение.
5. Скрипт [`scripts/derive_ip.py`](scripts/derive_ip.py) собирает компактный `amnezia-ip-lite.json`: резолвит домены из категорий и заменяет каждый адрес на содержащий его префикс из `ru.txt`. Получается ~650 подсетей вместо 12 840 — и точнее, потому что внутри только сети реальных сервисов.
6. Обновлённые файлы коммитятся в репозиторий и публикуются в релиз `latest`.
7. Отдельный workflow [`glinet.yml`](.github/workflows/glinet.yml) каждый день скачивает `ru.txt` и скриптом [`scripts/extract_glinet.py`](scripts/extract_glinet.py) собирает из его IPv4-подсетей `glinet-ip.txt`. Коммит появляется, только когда источник изменился, — примерно раз в месяц. Если список сократился больше чем на четверть, это считается сбоем источника, и файл не перезаписывается.

> В этом форке шаги 1–6 запускаются только вручную (Actions → Build Amnezia Domain List → Run workflow), по расписанию работает только шаг 7.

Всё прозрачно: источник данных открыт, скрипт конвертации — 40 строк Python в этом репозитории.
